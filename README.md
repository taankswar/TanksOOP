# Танки — пошаговая тактика

Пошаговая игра в танки на поле 20x20 с препятствиями.

## Механика

- Поле 20x20 клеток
- Танки движутся по 4 направлениям (вверх, вниз, влево, вправо)
- У каждого танка 4 зоны брони: лоб, левый борт, правый борт, корма
- Пробитие определяется сравнением брони зоны и пробития орудия
- HP общее на весь танк

## Классы техники

- **Лёгкий танк**: быстрый (5 клеток/ход), слабая броня, урон 25, пробитие 40
- **Средний танк**: сбалансированный (3 клетки/ход), средняя броня, урон 35, пробитие 55
- **Тяжёлый танк**: медленный (2 клетки/ход), толстая броня, урон 50, пробитие 75

## Воспроизводимость

Все случайные величины (генерация карты) используют один генератор с задаваемым seed.
